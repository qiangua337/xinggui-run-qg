# 星轨跑酷 · NIGHTLINE RUN

双击同文件夹中的「星轨跑酷.html」，用 Chrome 或 Edge 打开即可游玩。游戏画面、人物和音效都在文件内，无需安装、登录或联网。

## 操作

| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 左右换道 | ← / → 或 A / D | 左右滑动或点击按钮 |
| 跳跃 | ↑ / W / 空格 | 上滑或点击跳跃按钮 |
| 下滑 | ↓ / S | 下滑或点击下滑按钮 |
| 暂停 / 继续 | P / Esc | 右上角暂停按钮 |

列车需要换道躲开；矮路障可以跳过；横杆需要下滑。跑得越远，速度越快。音效可用右上角喇叭按钮开启。

## 选择模式

起点可以选择「经典跑酷」或「极速挑战」，选择会自动保存。

经典模式从 14 m/s 起跑，逐渐加速至 27 m/s。极速模式从 22 m/s 起跑，加速更快，最高 36 m/s；障碍间隔更短，也更容易遇到两条跑道同时有障碍的布局。每组新障碍都留有可通行跑道。

极速模式的跑步积分为 1.5 倍，双倍积分道具可继续叠加。金币积分、两次免费复活和各档奖励仍按原规则提供。运行中显示模式和当前速度。模式只能在起点切换，暂停、复活和重新开始都会保留本局模式。

## 角色与穿搭

「角色与衣橱」中可以选择奶龙、蓝色胖猫和猪猪侠的卡通版本。三种角色有不同的身体轮廓、五官、尾巴和跑步动作，使用相同的碰撞规则。

每个角色可单独调整上衣、裤子、帽子和鞋子的颜色，选择纯色、条纹或拼色，佩戴星徽、猫耳或耳机。拖动试衣区可以旋转角色。搭配会自动保存。

## 地图、道具与奖励

可在开始前或暂停时切换落日城市、霓虹夜城和雪境森林地图。

磁铁会自动收集附近的金币；护盾可挡住一次撞击；双倍积分会暂时提高跑步和金币的得分。

| 本局分数 | 奖励 |
| --- | --- |
| 300 | 9 秒护盾 |
| 800 | 10 秒磁铁 |
| 1500 | 永久解锁星冠配饰，送 10 秒双倍积分 |
| 3000 | 额外 1 次复活，并补充护盾 |
| 5000 | 磁铁、护盾和双倍积分同时生效 |

撞击后先有摔倒动作，再提供复活选择。每局有 2 次免费复活，保留当前得分和金币；复活前倒数 3 秒，恢复奔跑后另有 3 秒无敌保护。倒计时也能暂停，切出页面时会自动暂停。

## 本机排行榜

「经典榜」和「极速榜」分别记录当前浏览器中最高的 10 局成绩，包含角色、配饰、得分和距离。原有成绩继续保留在经典榜。成绩、穿搭和解锁状态保存在当前浏览器中；不同浏览器、不同网址或离线文件的记录分别保存。

## 参考与组件

角色为本小游戏制作的简化卡通模型，参考用户指定的形象。其中奶龙参考[第七印象官方角色介绍](https://www.nailoong.com/ipStar/Nailong/)，猪猪侠参考[角色图片](https://www.duitang.com/blog/?id=1250558300)。蓝色胖猫根据用户描述制作。

3D 画面使用 Three.js 0.160.1，采用 MIT 许可。源文件包保留其许可证。
